## What it is

A walkthrough of the data structures, algorithms and problem-solving patterns that coding interviews test, organised as one folder per topic, from arrays and two pointers through trees, graphs, dynamic programming, union-find and topological sort.

- **Concept notes:** when a pattern applies, its complexity, and a pseudocode sketch.
- **54 real LeetCode problems** (12 easy, 39 medium, 3 hard), each a self-contained Python file whose tests come from LeetCode's own examples. Problem statements were pulled from LeetCode's public API rather than written from memory.
- **Reference solutions** in a separate folder, each targeting the complexity an interviewer would expect, and each run to confirm its tests pass.
